<h2>Project Details</h2>

<h3>1. Mean-Variance-Standard Deviation Calculator</h3>

<p>Uses NumPy to calculate the mean, variance, standard deviation, maximum, minimum, and sum of a 3 × 3 matrix.</p>

<h3>2. Demographic Data Analyzer</h3>

<p>Analyzes demographic data using pandas to answer questions about population characteristics.</p>

<h3>3. Medical Data Visualizer</h3>

<p>Analyzes medical examination data and creates visualizations to explore relationships between health-related variables.</p>

<h3>4. Page View Time Series Visualizer</h3>

<p>Analyzes daily page-view data to identify trends and patterns over time.</p>

<h3>5. Sea Level Predictor</h3>

<p>Uses historical sea-level data and linear regression to predict future sea-level changes.</p>
